The previous M1 no-referrer modal played live video after a manual in-player tap. This separate experiment tests whether the same modal can begin playback immediately when opened, with no second tap.

Important: Dacast documents player-side autoplay configuration and allow="autoplay" iframe permission. It does not establish that the URL parameters tested below work on these live streams. Each parameterized case is an experimental hypothesis, not a documented Dacast API.

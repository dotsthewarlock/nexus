M1 · New inline test

Real modal + privacy-referrer iframe

Open the video inside a native modal using an iframe with referrerpolicy="no-referrer". The prior failed embedded tests did not establish the outcome of this exact setting. No auto-stop timer; start playback manually.

An iframe load event means only that a document loaded. The lab cannot inspect the cross-origin player's authorization response.

P2 · New windowed test

Compact browser popup window

Open the already-working top-level Dacast player in a requested compact popup (480 × 320) with noopener,noreferrer. On a Chromebook this may appear as a floating window. Android Chrome may use a new tab instead.

This is not an in-page video modal. Window size and placement are controlled by the browser.

H3 · Modal handoff UX

Nexus modal with a live-camera handoff

Open an app-style modal containing the verified new-tab, no-referrer direct player link. It tests whether users can launch a live feed and return without losing the selected camera or dashboard. This is a UX test, not another playback bypass.

V4 · OS-level overlay test

Native video Picture-in-Picture

Open the verified direct link in a new tab, play video, and look for a Picture-in-Picture (PiP) control on the player. If offered, activate it and return to Nexus. The video may float above Nexus independently of its page.

V4 · Open live feed for PiP trial

Chrome for Android supports the standard video PiP API, but Nexus cannot activate it within a cross-origin player. The Document Picture-in-Picture API does not support Chrome Android; this test uses only player/browser controls.
